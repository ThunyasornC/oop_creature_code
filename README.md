
# Creature Battle Project (OOP + Git Branching Practice)

This project is designed to help me learn **object-oriented programming** in Python, especially **inheritance**, while also practicing key **Git concepts** like branching, merging, conflict resolution, and version history.

## Learning Objectives

### Python / OOP
- Understand and implement classes
- Use inheritance to extend behaviors
- Override and extend methods (e.g., attack())
- Practice writing simple test code in main

### Git / Version Control
- Create and switch branches
- Merge branches into main
- Resolve merge conflicts
- View commit history

## Project Structure

```text
oop_creature_code/
├── creature_simulation.py
└── README.md
```

## Classes

- Creature: Base class with name, HP, and attack power.
- FlyingCreature: Can fly and perform aerial attacks.
- SwimmingCreature: Can dive and perform underwater attacks.
- FireCreature: Can emit fire and perform fire-based attacks.

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open a terminal.
4. Run:

```bash
python creature_simulation.py
```

5. Check the output of all creature tests.

## Git Branches

- main
- flying_creature
- swimming_creature
- fire_creature

## Conclusion

This project demonstrates Python inheritance, method overriding, Git branching, merging, and merge conflict resolution.
